Conventions
  • /api/auth/*, /api/meta, /api/i18n/*, /api/avatar* are shared across v1 and v2.
  • /api/* outside that list is v1 — frozen.
  • /api/v2/* is the actively developed surface.
  • Auth header: Authorization: Bearer <wall jwt>.
  • Time fields are ISO-8601 UTC.
  • Pagination uses cursor (last created_at you saw) + limit.

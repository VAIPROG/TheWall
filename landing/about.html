The Wall Dev is a fan-made extension for filianislost.com — the pixel-canvas project run by streamer Filian.

It was built by the Russian-speaking part of Filian's community by VAI_PROG (vai on wall) — first as a quick aiming helper for fixing tiny specks on the canvas, then steadily grown into a full Win95-themed companion: a Community hub with clans, chats & DMs, templates, and Discord & Telegram bots that sync the wall both ways.

Everything is fair-play. No autopainting, no captcha bypass, no WebSocket injection. We never paint for you — we just help you aim and keep your clan organised.

How integration works Как работает интеграция Wie die Integration funktioniert Fonctionnement de l'intégration

The Wall Dev does NOT modify the site's source code in any way. It works entirely through the browser extension API and only uses features that the site already exposes publicly:

  • Reads the public tile layer — the same PNG tiles your browser downloads to display the canvas.
  • Reads your existing session cookie — the one the site already set when you logged in. We never create, forge, or manipulate cookies.
  • Sends pixel placement requests through the site's own public API — the same endpoint the site's UI calls when you click a pixel.
  • Overlays a UI layer on top of the page via standard DOM injection (same as any browser extension). No elements of the original page are modified or removed.

In short: we call the same public endpoints that any browser session calls. We don't patch, hook, or intercept any of the site's JavaScript, WebSocket connections, or network traffic. The site's code runs exactly as the developers shipped it.

The Wall Dev НЕ изменяет исходный код сайта никаким образом. Расширение работает исключительно через API браузерных расширений и использует только те функции, которые сайт уже предоставляет публично:

  • Читает публичный слой тайлов — те же PNG-тайлы, которые ваш браузер скачивает для отображения холста.
  • Читает вашу существующую сессионную куку — ту, которую сайт сам установил при входе. Мы никогда не создаём, не подделываем и не манипулируем куками.
  • Не отправляет запросы на размещение пикселей и не вызывает функции покраса сайта.
  • Накладывает UI-слой поверх страницы через стандартную DOM-инъекцию (как любое браузерное расширение). Никакие элементы оригинальной страницы не модифицируются и не удаляются.

Коротко: мы вызываем те же публичные эндпоинты, что и любая браузерная сессия. Мы не патчим, не перехватываем и не модифицируем JavaScript сайта, WebSocket-соединения или сетевой трафик. Код сайта работает ровно так, как его выпустили разработчики.

The Wall Dev verändert den Quellcode der Seite NICHT. Es arbeitet ausschließlich über die Browser-Extension-API und nutzt nur Funktionen, die die Seite bereits öffentlich bereitstellt:

  • Liest die öffentliche Tile-Schicht — dieselben PNG-Tiles, die Ihr Browser zum Anzeigen der Leinwand herunterlädt.
  • Liest Ihr bestehendes Session-Cookie — das, was die Seite beim Login gesetzt hat.
  • Sendet Pixel-Platzierungsanfragen über die eigene öffentliche API der Seite — denselben Endpunkt, den die Seiten-UI beim Klicken aufruft.
  • Legt eine UI-Schicht über die Seite per Standard-DOM-Injektion (wie jede Browser-Extension).

Kurz: Wir rufen dieselben öffentlichen Endpunkte auf wie jede Browser-Sitzung. Kein Patching, kein Hooking, kein Abfangen von JavaScript, WebSocket oder Netzwerkverkehr.

The Wall Dev ne modifie PAS le code source du site. Il fonctionne entièrement via l'API d'extension du navigateur et n'utilise que les fonctionnalités que le site expose déjà publiquement :

  • Lit la couche de tuiles publique — les mêmes PNG que votre navigateur télécharge pour afficher le canevas.
  • Lit votre cookie de session existant — celui que le site a défini lors de votre connexion.
  • Envoie des requêtes de placement de pixels via l'API publique du site — le même endpoint que l'UI appelle quand vous cliquez.
  • Superpose une couche UI par-dessus la page via l'injection DOM standard (comme toute extension de navigateur).

En résumé : nous appelons les mêmes endpoints publics que toute session de navigateur. Pas de patch, pas de hook, pas d'interception du JavaScript, des WebSocket ou du trafic réseau du site.

Tech stack Технологии Tech-Stack Stack technique
  • Frontend: TypeScript + esbuild → single IIFE bundle, no runtime deps.
  • Backend: Rust + Axum + SQLx + Postgres, serving the V3 API at /api/v3/*. WebP via the image crate.
  • Bots: Discord + Telegram on one unified command framework, syncing the wall and clans both ways.
  • Browser support: Chrome / Edge / Brave (MV3), Firefox 128+, Safari 16.4+, Tampermonkey.
  • Build: bun run build → user.js + chrome ext + firefox ext + zip + signature.json.
  • Infra: nginx + Let's Encrypt + systemd on a small Hetzner-class VPS.
